# 객체지향

- 데이터와 데이터를 다루는 행동을 한 객체로 묶고 객체 간 협력하도록 설계

```java
class Order {

    private OrderStatus status;
    private int totalPrice;

    public void cancel() {
        if (status == OrderStatus.SHIPPED) {
            throw new IllegalStateException("배송된 주문은 취소할 수 없습니다.");
        }

        this.status = OrderStatus.CANCELED;
    }
}
```

- 상태와 행동을 가진 객체

## 이 책임은 누가 가져야 하는가?

```java
class OrderService {

    public void cancel(Order order) {

        if (order.getStatus() == OrderStatus.SHIPPED) {
            throw new IllegalStateException();
        }

        order.setStatus(OrderStatus.CANCELED);
    }
}

orderService.cancel(); // 서비스가 취소
order.cancel(); // 주문이 취소
```

- 외부에서 하나씩 조작 << 객체에 일을 요청하는 방향
- 각 객체가 자신의 책임을 수행하도록 만든다.

```
OrderService
    │
    ├── Product에게 가격 확인 요청
    │
    ├── Coupon에게 할인 요청
    │
    ├── Order에게 주문 생성 요청
    │
    └── Payment에게 결제 요청
```

- 다른 객체와 메시지를 주고받는다.
- 객체간의 협력을 통해 기능을 완성한다.
- 변경의 영향을 격리
